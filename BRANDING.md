# GoreeCloud Social — Branding

## Canonical identity

- Full product name: **GoreeCloud Social**
- Approved short label: **Social**
- Brand relationship: **Prefixed GoreeCloud family product**
- GoreeCloud Suite member: **Yes**
- Repository: `GoreeCloud/goreecloud-social`
- Package/application suffix: `social`
- Intended reverse-DNS identifier: `com.goreecloud.social`

The full canonical name should be used in standalone product documentation, public product pages, release descriptions, About surfaces, and other contexts where GoreeCloud ownership is not already obvious.

The short label `Social` may be used inside a clearly branded GoreeCloud application switcher, navigation surface, or compact client shell without renaming the canonical product.

## Visual identity

The canonical Social icon, logo, and artwork have not yet been accepted. Temporary interface marks must not be represented as final visual identity.

Glaze UI governs interaction and interface design. A Glaze-oriented development shell does not by itself constitute Glaze UI conformance or product visual-identity acceptance.
